# KeyLogger-Detection
<br>
Author : Dhirendra Kishor Shah
<br>
Keylogger and Detection System is an excellent way to understand both malware mechanics and endpoint defense. We will use Python for both 
<br>
components.
What is KeyLogger: A keylogger (short for keystroke logger) is a tool or program that secretly records every key you press on a keyboard.
<br>
It captures everything you type, including passwords, credit card numbers, private messages, and search queries. The recorded data is then sent
<br>
to an unauthorized third party or hacker.
<br>
Uses of KeyLogger
<br>
<b>Legitimate Uses</b>
<ul>
  <li>Parental Control.</li>
  <li>Employee Monitoring</li>
  <li>Law Enforcement</li>
</ul>
<br>
<b>Malicious Uses</b>
<ul>
  <li>Stealing Passwords</li>
  <li>Financial Fraud</li>
  <li>Spying</li>
</ul>
